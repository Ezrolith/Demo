# Package H continuation

Candidate branch: `chatgpt/story-h-validation`. Based on the inherited, unverified `claude/iter2-wip-H` work. The shipped branch is not changed by this review.

## Changes in this continuation
- Added `tests/story.mjs`: 24 targeted checks for endings, story flags, presses, officers, the three getaway outcomes, river rescues and the watch interaction. Powers/interactions use real game inputs. Setup may position the player or an entity; this is not an unassisted whole-game playthrough.
- Fixed checkpoint restoration: retain the identities of wounded officers and disabled presses, not merely their counts. Apply carried press state when entering the warehouse too. Optional integer masks use the existing story-flag format; older count-only saves retain a compatible fallback.
- Added an ending payoff for disabling both counterfeit presses and revised two concluding passages.
- Added a disposable scene chooser (`dist/story-preview.html`) so reviewers can see the changes without replaying the opening. It bypasses production save reads/writes before game boot.
- Added `tests/story-preview.mjs` to exercise all six chooser options and verify save isolation, including reset.

## Validation

```sh
npm test                    # the original nine regression suites, sequentially
npm run test:story          # 24 focused story checks
npm run test:preview        # build both HTML files; chooser and save-isolation checks
```

The local offline browser harness passed the targeted game-logic checks and was used to inspect screenshots. Its storage was in-memory because this environment blocks browser navigation; actual file loading and browser storage are checked separately by GitHub Actions. Do not treat the local harness alone as full regression verification. The PR's workflow result is the source of truth for full validation.

Screenshots are retained as workflow artifacts under `tests/out/story/`. The standalone production build is generated by `tools/build.mjs`; never edit it by hand. The preview is generated by `tools/build-story-preview.mjs`.
